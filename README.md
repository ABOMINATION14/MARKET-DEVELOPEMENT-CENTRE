# 🛒 Market Development Centre

A complete **Buy & Sell marketplace** web application designed to be **simple and user-friendly for everyone**, including less-educated and former/uneducated people.

## ✨ Features

### 🛍️ Buy Products
- Browse fresh fruits, vegetables, dairy, groceries and drinks
- Big, easy-to-press **"Add to Cart"** buttons
- **Voice search** - just press the mic and speak
- Simple search by typing or speaking
- Category filtering

### 💰 Sell Products
- Farmers and sellers can **list their products** easily
- Simple form with pictures and clear labels
- Reach thousands of customers
- Manage your own product listings

### 🛒 Shopping Cart
- Add, remove, and change quantities
- Order summary with delivery charges
- Free delivery on orders above $50

### 📦 Checkout
- Easy order form (name, phone, address)
- Multiple payment options (Cash, Card, UPI)
- Order confirmation with order number

### 📊 Analytics Dashboard (c3.html)
- Total sales, orders, products statistics
- Weekly sales chart (C3.js)
- Category sales donut chart
- Recent orders list

### 👤 User Accounts
- Register as Buyer, Seller, or Both
- Login/Logout
- Profile page with order history

## 🚀 How to Run

### Web Application
Just open `index.html` in any web browser. No installation needed!

### Java Programs
```bash
# Compile
javac ShoppingCart.java
javac SearchProduce.java

# Run
java ShoppingCart
java SearchProduce
```
